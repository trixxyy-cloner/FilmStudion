# FilmStudion

## Krav / Teknik

- **.NET SDK 8.0+**
- **Node.js & npm**

## Starta API:t

- **Öppna git bash eller valfri terminal och ställ dig i repots root**
- **dotnet run --project API/API.csproj**
- **Api startar på http://localhost:5254**

## Testa API:t

- **Starta API:t**
- **Öppna API.http i VScode**
- **Klicka på "send request" ovanför requesten du vill testa (Kräven REST client extension)**

## Starta Frontend

- **Öppna en ny terminal (stäng ej ner api-terminalen)**
- **cd FrontEnd**
- **npm install**
- **npm run dev**
- **Öppna http://localhost:5173**

## Användandet av Frontend
- **Besökare kan se alla filmer men inte låna/lämna tillbaka**
- **Registrera en användare för att kunna låna film/lämna tillbaka film**
